## 📝 Deskripsi
**NataEdu** adalah solusi digital untuk mahasiswa dan pelajar yang ingin memperdalam materi perkuliahan maupun kursus. Aplikasi ini menjembatani interaksi antara pencari ilmu dengan mentor ahli di bidangnya.

## 🚀 Fitur Utama
- ✅ **Course & Materials**: Akses materi pembelajaran terstruktur.
- 👨‍🏫 **Mentor Expert**: Konsultasi langsung dengan ahlinya.
- 🔍 **Smart Search**: Cari materi favoritmu dalam hitungan detik.
- ⚙️ **Admin Dashboard**: Panel kontrol khusus untuk manajemen data.

## 🛠️ Tech Stack
- **UI & Layout**: XML dengan Material Components.
- **Image Loading**: [Glide](https://github.com/bumptech/glide) untuk manajemen gambar yang efisien.
- **Networking**: OkHttp untuk komunikasi data.
- **Backend**: Firebase Firestore (Database) & Firebase Storage.
